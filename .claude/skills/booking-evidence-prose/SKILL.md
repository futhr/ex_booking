# Booking evidence prose

Use precise interval, timezone, ambiguity, ordering, and caller-ownership language. Separate an
example from a property, a focused test from the full gate, and local package inspection from a
real downstream consumer.

Keep examples runnable with the current public API and pins. Regenerate notebook outputs after
behavior changes. Remove generic claims, filler, comments that restate code, invented benchmark
language, and text that could describe any Elixir library.

Research may describe external designs but must not imply copied implementation or accepted
normative behavior; specs own the contract.
